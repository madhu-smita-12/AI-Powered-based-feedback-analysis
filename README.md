# AI-Powered Aspect-Based Customer Feedback Analysis

## Description
This project analyzes customer reviews using Artificial Intelligence and Natural Language Processing. It extracts product aspects such as Battery, Camera, Display, and Build Quality, determines the sentiment for each aspect, and generates an intelligent summary to help customers and businesses make better decisions.

## Technologies
- Python
- SpaCy
- Hugging Face (RoBERTa)
- LangChain
- PostgreSQL
- Streamlit
